# Мой Кинопоиск для Lampa

Плагин выводит на главной «Буду смотреть», историю оценок и два ряда рекомендаций. Кнопка «Ещё» открывает полный список со страницами по 20 карточек. В открытой карточке личная оценка подписана «Моя оценка КП». У просмотренного фильма без оценки появляется подпись «Просмотрено на КП».

## Установка по ссылке с GitHub

Отключите предыдущую копию этого расширения. В Lampa откройте **Настройки → Расширения → Добавить плагин**, вставьте адрес ниже и перезапустите приложение.

```text
https://savitsky4sasha.github.io/lampa-kinopoisk-profile/profile.js
```

Эта версия читает опубликованный в репозитории файл `feed/profile.json`. Компьютер и дополнительная служба на телевизоре для неё не нужны. GitHub Actions сверяет публичные списки КП дважды в час. При сбое остаётся последняя полная копия. GitHub может задерживать выполнение расписания. Файл содержит историю просмотров и оценки в открытом виде. При настройке собственного репозитория владелец выбирает профиль в ручном запуске workflow «Refresh Kinopoisk profile».

## Работа на LG без компьютера

На LG с уже настроенным webOS Homebrew можно запустить загрузчик прямо на телевизоре. Публичные страницы Кинопоиска запрашивает сам LG по HTTPS. Lampa получает расширение и снимок профиля внутри телевизора по HTTP.

1. Скопируйте на телевизор в одну временную папку три файла: `webos-install.sh`, `profile_server.py` и `profile.js`.
2. Из этой папки, в уже настроенном административном терминале телевизора, выполните `sh webos-install.sh PROFILE`. Вместо PROFILE укажите числовой ID или псевдоним своего публичного профиля. Установщик проверит наличие системных Python, curl и каталога автозапуска Homebrew, сохранит профиль локально и запустит службу на 127.0.0.1 от пользователя nobody. После перезапуска LG служба запускается автоматически. Если при повторной установке старая версия уже работает, выключите и включите ТВ для перезапуска службы.
3. В Lampa отключите прежнюю копию «Мой Кинопоиск» с адресом компьютера и добавьте `http://127.0.0.1:8766/kp.js` через «Настройки → Расширения». Перезапустите Lampa. При первой синхронизации телевизор читает обе коллекции целиком.

Служба проверяет изменения, пока ТВ работает. Во время выключения обновление продолжится при следующем запуске. GitHub содержит исходники для установки и обновления. Список фильмов и личные оценки хранятся на телевизоре. Эта схема использует уже установленный Homebrew и не подходит для обычного браузера компьютера.

## Установка с сервером на компьютере

Нужны Lampa с поддержкой ContentRows и компьютер с Python 3.9+ в одной сети с телевизором. Публичные списки читает компьютер. Пароль Яндекса и ключ API не требуются.

1. Скачайте `profile.js` и `profile_server.py` в одну папку. Откройте терминал в этой папке.
2. Запустите команду ниже. Замените `PROFILE` на псевдоним или числовой ID профиля, а адреса из примера — на адреса своего компьютера и ТВ.
3. В **Настройки → Расширения → Добавить плагин** укажите `http://192.168.1.10:8766/kp.js` с адресом своего компьютера и перезапустите Lampa. При запуске сервер загружает страницы КП. Открытая главная покажет полученные списки автоматически.

```sh
python3 profile_server.py PROFILE --bind 192.168.1.10 --tv 192.168.1.20
```

## Автообновление

Пока домашний сервер работает, он каждые пять минут проверяет число записей и первую страницу очереди и истории, отсортированных по последним изменениям. При изменении перечитывает все страницы соответствующего списка. При запуске и раз в шесть часов он сверяет оба списка целиком, включая старые записи. Интервал быстрой проверки меняется параметром `--interval` в минутах.

Сервер публикует снимок только после проверки количества и уникальности карточек. Если КП недоступен, он сохраняет последнюю полную копию и повторяет проверку в следующем цикле. Синхронизация на компьютере работает и при выключенном телевизоре.

Открытая Lampa раз в минуту и при возвращении в приложение проверяет версию снимка. При изменении обновляет личную оценку в открытой карточке и ряды на главной. При работе с пультом обновление главной откладывается до паузы. Во время воспроизведения экран не переключается. Новые рекомендации рассчитываются по обновлённым оценкам.

## Как подбирается кино

- **Из моего списка по вкусу** ранжирует отложенные фильмы по жанрам. Высокие оценки жанру повышают его вес, низкие понижают. Уже просмотренные исключаются по ID КП.
- **По моим высоким оценкам** берёт до четырёх любимых фильмов или сериалов с оценкой 8–10 и запрашивает похожие тайтлы у TMDB через Lampa. Повторные попадания повышают позицию. Совпадения с историей и очередью отбрасываются по типу, названию и году. Различия между каталогами могут мешать сопоставлению.

В списках остаются все импортированные карточки. Для открытия карточки в Lampa плагин ищет однозначное совпадение в TMDB по типу, году и названию. Если такого совпадения нет, он показывает сообщение. Визуальные метки относятся к личному профилю КП. Импорт не записывает историю в аккаунт CUB, не выставляет оценки в КП и не меняет таймкоды КиноПаба.
